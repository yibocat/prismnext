## 👋 先看一眼：它在干什么？



不是又一个「只会改代码的聊天框」，也不是「隔夜交稿」的黑箱。  
PrismNext 把**读文献 → 想清楚 → 跑实验 → 写成稿 → 审一遍**放进同一个本地 App，AI 可以帮你推，但**闸门在你手里**。

---



## 🎯 适合谁？

- 🎓 **博士 / 硕士 / 科研人员** — 论文、实验、引用天天打交道  
- 👥 **小团队共写** — 同一仓库、Git / worktree、AI 辅助但不乱改  
- ✍️ **认真写 LaTeX 的人** — 要 SyncTeX、编译、diff，而不是纯 Markdown 凑合  
- 🛡️ **在意数据主权的人** — 手稿和文献库留在本机，Key 自己带（BYOK）

如果你只想「随便问两句文献」，它可能偏重；  
如果你想**天天开着干活**，它就是为这个场景长的。

## 🧰 功能全景



### 📚 文献

- 项目级**文献库**（SQLite），PDF 精读，不是飘在云端的临时对话附件  
- 元数据 enrich：Crossref / arXiv / OpenAlex 等  
- BibTeX 导入导出、引用暂存与 citation health  
- 论文检索后可 **stage 进本地库**，越用越像「自己的书房」



### 🧭 研究设计

- **Research Brief** — 活的设计笔记（跟着项目走）  
- **Plan 工作流** — Build | Plan；Agent 提议进入 Plan 前会征求同意  
- 草稿 → **Approve** → Checklist，避免「聊着聊着就改飞了」



### 🧪 实验

- 实验岛、run 日志、产物快照  
- **Provenance**：这张图 / 这个结果从哪次命令来的，写 Methods 时有据可查



### ✍️ LaTeX 写作

- TeX 工作区（大纲、查找、语言支持）  
- **pdf.js 预览 + SyncTeX** 双向跳转  
- Tectonic（默认）或 TeXLive；`% !TEX program` / `% !TEX root`  
- **Proposed Changes**：Merge 视图审 AI 修改，逐条或批量接受 / 拒绝  
- 导出 PDF 或源码 zip



### 🤖 Agent 共驾

- 多标签对话、流式输出  
- 编排器 + 专家（文献 / 设计 / 方法 / 结构 / 同行评审等）  
- Skills · 斜杠命令 · Knowledge Modules · 项目 Rules  
- 权限模式：询问 / 编辑自动 / 全自动 / 只读

你可以：


| 模式            | 感觉                           |
| ------------- | ---------------------------- |
| 👤 **你主导**    | 自己写、自己编译，偶尔问 Agent           |
| 🤝 **共驾**     | Agent 推进设计 / 实验 / 写作，重要节点你批准 |
| 🛰️ **AI 主导** | 工作面最大化监测，胶囊栏轻干预              |




### 🛠️ 日常工程壳

- Git：状态、暂存、diff、提交、分支、merge、stash  
- Worktree：并行写作上下文  
- 终端 + AI bash  
- 应用内浏览器  
- 模板：论文 / 学位论文 / Beamer / 海报 / CV / 信函  
- 界面语言：English · 简体中文 · 繁體中文（香港）  
- 打包版支持**应用内更新**

## 🚀 怎么用？



### 1️⃣ 安装

从 [下载页](./website/)（或你的发布渠道）获取 **macOS** / **Windows** 安装包，装好打开即可。

> 💡 macOS 若提示「已损坏」，多半是未签名隔离：对 `.app` 执行一次 `xattr -cr` 后再开。



### 2️⃣ 打开或新建项目

选一个文件夹当科研项目根目录。PrismNext 会在其中维护 `.prismnext/`（文献库、brief、实验、编译缓存等）——**都在你磁盘上**。

### 3️⃣ 接上你的 AI

打开 **设置** → 填入供应商与 API Key（BYOK）。  
没有「把毕业论文上传到我们云」这一步。

### 4️⃣ 开工

1. 📚 把论文丢进文献库，或检索后入库
2. 🧭 在 Brief / Plan 里把问题与路径写清楚
3. ✍️ 在 TeX 里写，PDF 预览对着改
4. 🧪 需要时挂上实验 run 与产物
5. 🤖 卡住了就对话；大改动走 Plan / 权限闸门
6. ✅ 看 Proposed Changes，接受你真正想要的修改

## 🔒 本地优先，意味着什么？

- 手稿、文献库、实验记录、Agent 配置 → **本机**  
- 模型调用 → **你的 Key**  
- 可选联网（enrich / 检索 MCP 等）→ **显式触发**，不是默默把项目同步走

适合处理未发表数据、敏感稿件，以及「我不想把整个课题交给某个 SaaS」的场景。
