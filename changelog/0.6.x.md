# Changelog — 0.6.x series

## 0.6.6 — 2026-08-01

### Task / Experts

- Background Task (P1): pass `background: true` so the main agent can keep working while subagents run; join via OpenCode inject / child session status (match by child id); Task cards show **Background**; omit `background` stays sync
- Sync Task hardening: nested Task deny, Plan mode may Task explore/experts, `@Expert` allowlist + follow-up, structured errors, Subagent model setting, and reliable Stop (ACP cancel + HTTP abort, two-phase Stopping→Stopped)
- Task run panel: composer-width mini-chat (SQLite hydrate when ACP is quiet), Esc / click-outside dismiss, historical reopen, taller AiBar/Task float panels

### Chat activity

- Cursor-style activity folds: **Planning / Exploring / Editing / Executing** bursts with inventory lines; real **Worked for / Thought for** timings; one settled Worked-for wrap; Task cards stay outside the fold
- TodoWrite **Task plan** drawer under the user message bubble (follows the latest user while open; pins when complete; ✕ hides UI only)
- Turn failures and OpenCode Go/Zen quota / rate-limit / stream errors from `opencode.log` print into the assistant reply; wait copy stays **Planning next step…**
- Fix mid-turn Worked-for flicker and user bubbles overwritten by a later 「继续」display snapshot

### Models & providers

- Bundled OpenCode **1.18.10**; reasoning depth (Edit) from the live catalog; Go/Zen model lists sync from `models.json`
- Lazy provider catalogs: OpenAI / Google / DeepSeek join Add provider; OpenRouter **Fetch all models**; DeepSeek (and other former built-ins) stay removed after Remove → restart
- Model picker polish (content-driven width, Edit panel, `/` → Models, ⌥K / Alt+K)

### Permissions & reliability

- Settings → Permissions: allowed paths, allow/deny rules, rule tester, and composer Always patterns; smarter delete/move gates; slash `!`cmd`` follows the same policy
- Cold OpenCode start: sync experts/skills before first spawn; fewer false credential restarts on first send
- Typing lag fixed (debounced draft persist); turn watchdog for silent/stalled providers; Stop completes the UI immediately

### Interaction

- Static figures (`figure.static`) and CSV plots (`plot.line` / `series` / `scatter`) in RightArea; specs under `.prismnext/interactions/`; chat peeks and interaction tools

### Composer & UI

- Composer chrome stack above the input (Question / permission / experiment cards, Sonner-style overlap)
- Chat + Files markdown share reading rhythm; Files `.md` preview uses UI Font size like chat replies
- Paper Search MCP is optional and no longer eager-connects on every `session/new`

### Fixes

- In-app Browser redirect loop; file-tree blank click clears selection; context ring default 128K and refreshes when the Go/Zen catalog loads
- Public-repo metadata and download landing page (theme + feature sections)
