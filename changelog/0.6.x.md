### Chat

- Cmd+K command palette: category tabs and history actions respond on first click; Tab / ↑↓ work without remounting cmdk when sessions finish loading
- Cmd+K file open: use project-relative paths and load file content via the same path as the file tree (fixes empty/wrong-path editor tabs)
- Chat homepage: restore narrow-layout composer at bottom (`justify-end`); wide center panel keeps vertically centered input (`@xl:justify-center`)
- Context ring prefers OpenCode ACP `usage_update` (`used` / `size`) over hand-rolled `input+cache` and chars/4 estimates
- Context panel defaults to used/size only; optional collapsed **two-bucket** Prism estimate (Prism-injected vs session/agent remainder) — no more fake Messages/Agent Base categories
- Compress clears ring usage until the next OpenCode report (no more stale high %)
- Tool expand panels (incl. TodoWrite / Task plan drawer) use opaque `bg-muted` instead of `bg-muted/20` so they no longer look hollow on dark chat
- User message bubbles use `bg-card` (same as the composer input shell) so they stay distinct from Task plan / tool drawers (`bg-muted`)
- Every turn’s user bubble sticks at the top while that turn is in view; same `mx-3` inset as main AI Chat (AiBar / Task float share `ChatMessages` — no full-bleed `-mx` that glued bubbles to panel edges)
- AiBar / Task float panels use opaque `bg-background` in both light and dark (bubbles stay `bg-card`)

### Theme

- Shell chrome edges: shared `--shell-edge-line` / shadow tokens for center↔RightArea sash, WorkspaceSplit dividers, RightArea mode sidebar, and softer `--toolbar-edge-line` under toolbars (left nav keeps `--sidebar-edge-line`)
- UI borders: theme packs now emit softened `--border` / `--border-subtle` / `--input` (opaque color-mix) for cards, chat bubbles, command palette, AiBar, and form fields; light-mode shell lines bumped for readability
- Markdown: tables, blockquotes, rules, code frames, and embedded media use the same border tokens (outer `border-border`, inner grid/dividers `border-border-subtle`)
- Chat artifact thumbnails (images, PDF peeks, interaction previews): fixed `h-52` preview viewport with `object-contain` so inline cards stay a consistent size
- Light neutral shell: `background` L 0.97→0.96; `card`/`popover` 1.0→0.97; `muted`/`sidebar` stepped to keep card > background > muted > sidebar
- Dark neutral shell: softer contrast — canvas lifted, foreground softened (`background` 0.22, `foreground` 0.86, `card`/`sidebar` 0.26, `muted` 0.30)
- UI text rendering: `optimizeLegibility` + optical sizing; dark mode uses grayscale font smoothing (macOS/WebKit) to reduce harsh halation on non-white text
- Soften PDF night invert to a middle ground (less crush than before, not washed-out) and sit pages on `background` canvas chrome
- Appearance typography: pick **system-installed fonts** with search; remove bundled @fontsource / local woff2 faces (legacy curated ids migrate to System)
- Appearance UI / Editor font controls match other settings density (`h-6` triggers + tighter dropdown)
- System font listing works on macOS / Windows / Linux via `font-list` (asar-unpacked); monospace sort uses OS metadata + name heuristics
- Chat backdrop (homepage + active sessions): styles include academic watermark, scribbles, night rain, falling leaves, blueprint, starfield (twinkle + meteors), circuit traces, bookshelf, ink strokes, clips & bookmark, paper planes, draft stamp; **Default** follows theme pack; master toggle + style picker in Appearance → Chat Layout

- Casual desk motifs kept: clips/bookmark, paper planes (glide across), draft stamps; remove coffee / window / scatter / film grain

- Five quiet motifs: pendulum + hourglass, axis corner, constellation line art (ink droplets removed)

- Remove cat / inkdrop / axes chat backdrops (legacy settings map to Default)
- Starfield backdrop: smaller dots, upper-sky bias, slower gentle twinkle (fewer blinking stars)
- Starfield backdrop: dark mode — sketch crescent moon + twinkling stars; light mode — sketch sun + drifting hand-drawn clouds
- Starfield backdrop polish: round sun/moon discs; softer round-puff clouds (fewer, cleaner silhouette)
- Starfield dark mode: restore meteors (~2–4.2s apart, occasional double streak)
