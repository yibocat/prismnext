# Changelog — 0.6.x series

## 0.6.8 — 2026-08-04

### Workspace

- **RightArea launcher**: open an empty RightArea to pick a mode from a vertical column of flat cards (icon · label · shortcut); modes come from the registry (same as「+」). Closing the last tab collapses RightArea — does not return to the launcher
- RightArea「+」menu shows split-open keyboard shortcuts (same chords as Cmd+K)
- **Settings** RightArea only shows settings-editor tabs; leave Settings to restore workspace tabs; closing the last settings detail tab collapses the panel (no empty placeholder)

### Chat & drag-and-drop

- Drag files, literature, PDF MinerU blocks, experiments, browser URLs, RightArea tabs, Git changes, and editor selections into **Chat / AiBar** as inline chips; OS file drops still attach as files
- AiBar capsule (maximized editor) accepts the same drops as the split chat panel; Browser reserves space so the webview does not cover the capsule
- Composer drag ghost is compact (not a full page capture); one chip per drop
- Literature drag grip lives on the MD slot so marquee multi-select and drag do not fight; Add to Chat and selection chips track the selection more reliably

### Project rules & brief

- Agent can write **Project rules** via `project-rule-write` (Settings → Rules); suggestions ask before writing
- Project rules are **global only** — removed per-agent Rules pickers
- Research brief lives at project-root **`.brief.md`** (auto-migrates; hidden in Files); Settings preview opens in the editor when needed

### Agent & prompts

- Knowledge modules attach by role; **orchestrator-judgment** on the primary orchestrator only; no per-agent module / MCP / Skills pickers in the agent editor (MCP and skills are session / project defaults)
- Deeper modules for literature, LaTeX workspace, project brief vs research design, experiments, interaction, scholarly reasoning, reply depth, subagent role, and core persona; thicker bundled orchestrator / expert instructions with a live expert roster
- Settings shows **token estimates** for prompt stack, modules, instructions, and Skills; context ring uses OpenCode-reported usage only
- Multimodal vision helper: reliable send path for text-only mains; wait copy follows 规划 → 识图 → 等待模型

## 0.6.7 — 2026-08-03

### Workspace

- RightArea rebuilt around **tabs +「+」** (Cursor-style): mode icon row removed; close a tab to leave a mode (no forced home reset); singleton modes hide from「+」when open; Terminal / Browser / Literature stay listed to spawn new tabs
- Files / Experiments / Literature: opening detail **replaces** the home tab in place; further opens add tabs; Literature「+」always spawns another Library home
- Mode open state is **derived from tabs only** (writable `activeModes` / `focusedMode` removed); `openMode` / `closeModeTabs` orchestration; Settings RightArea hides「+」and maximize (collapse kept)
- Fix chat / deep-link opens: expanding RightArea works again when the store flag was set before the panel resized

### TeX workspace

- Bundled Tectonic (like OpenCode) with a warm daemon for live compile; dirty-only flush, faster debounce; TeX Live only as silent fallback when Tectonic is missing
- PDF preview: A/B swap without jump-to-page-1; wait for Lector virtualizer before restore; live compile always publishes each successful PDF

### Literature

- Built-in `literature-discover` (arXiv / Crossref / OpenAlex / Semantic Scholar / PubMed); Paper Search MCP removed from product
- Session citation add: select-N add, cancel mid-download without leftover library rows; optional S2 / PubMed API keys in Settings

### Chat

- Click user bubbles to edit in place and resend after **world rollback**; clearer rollback / undo-rollback; composer send queue while streaming (Stop & Send)
- Inline tokens and markdown chips open files / papers / experiments; shared thin-border frames for intensive-reading figures and other chat images
- Context ring uses OpenCode `usage_update`; activity folds, Task plan drawer, background Task; Cmd+K and homepage composer polish

### Theme & Appearance

- Softer shell / border tokens; system-installed fonts; chat backdrops (starfield, bookshelf, paper planes, …) with ⌥T / ⌥B cycle shortcuts

### Models, permissions & reliability

- OpenCode **1.18.10**; lazy provider catalogs; Permissions settings (paths, rules, tester); faster cold start and Stop / typing fixes
