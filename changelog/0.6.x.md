# Changelog — 0.6.x series

## 0.6.5 (Unreleased)

### Experiments

- Clarify product language: experiment / working directory / run records (no “island”, “lab”, or “registry” in user-facing copy)
- Empty states and Settings → Workspace “Experiments root” describe the workspace root vs automatic bookkeeping
- Archived toolbar: pressed state is “Archived view” (active list hidden); hints explain how to switch back
- Create experiments from the panel (toolbar, empty state) without requiring Chat; opens the new experiment detail after create
- Detail shows a placeholder when no research brief is linked yet
- Navigation: sidebar is the experiment list (Files-like); click opens/focuses a detail tab (multi-tab). New + Active/Archived stay in the toolbar. Overview/Environment moved into the detail page for now
- Chat long runs: live command + output tail while `experiment-run` is in progress; open Experiments for the same live stream; clearer cancel / still-recorded messaging
- Chat run card: narrative summary (status · duration · truncated command · output) instead of raw run-id / ISO timestamps; technical fields behind Details
- Results tab on experiment detail: recorded run artifacts + read-only workspace scan (figures / tables / metrics); open in Files
- Editable experiment metadata: research brief links on the detail header (canonical Research Brief section multi-select + editable hypothesis / RQ); Literature-style tags on Overview; create dialog can set brief fields + tags
- Toolbar: Overview / Execution / Results via a Git-style dropdown button
- Overview: sparse label|value rows (no KPI cards); title + brief strip only on Overview
- Execution: history-first list with Literature-style row expand; bottom command composer; live output strip while running
- Execution toolbar: search + status/kind/sort filters (Overview/Results hide them); run list is flat (no pagination), like Git
- Execution: command composer under the toolbar; list shows note or short script title (not raw shell); expand uses sparse label|value rows with output collapsed by default
- Execution: Run is a lightweight toolbar dialog (no always-on composer); cancel available on the live strip while a run is in progress
- Execution list columns: run title · type · status · duration · finished time (attributes separated, not jammed into one line)
- Execution expand: editable notes, aligned label|value rows, hover-copy for command/ID (UI font), jump to Results from artifacts; Use in paper via list multi-select (not buried in the expand footer)
- Execution polish: Git/Literature native trailing checkboxes; click whole command/ID to copy with Overview-style hover icon + checkmark feedback; meta columns use Appearance UI font; filters left of search; Use in paper appears in toolbar when rows are checked (same muted toolbar chrome as Run)
- Opening an experiment shows the mode sidebar (experiment list) by default; Overview has a shortcut into Execution
- Experiments home: Files-style recent opens when experiments exist; mode sidebar opens reliably on first enter (no width race)
- Brief narrative links: open `.prismnext/research/brief.md` in Files from the experiment strip / section pills (jump to heading when linked); create & edit can fill hypothesis / RQ excerpts from the brief. Settings keeps a discovery entry only.
- Execution: select 2+ runs → Compare dialog (wide side-by-side: command / exit / duration / git / notes + best-effort metrics from run JSON artifacts)
- Execution expand: label|value rows use shared vertical-center alignment (same as Overview)
- Execution toolbar: when narrow, status/type/sort collapse into a filter popover; Run / Use in paper / Open lab become icon-only; search keeps a short placeholder
- Experiments home & sidebar: drop decorative flask icons (Files-style text list)
- Results: recorded artifacts grouped by type (figures with previews, tables, metrics, other); discovered figures no longer duplicate as chips under the preview grid
- Results: recorded artifacts grouped by run (type buckets inside); figure thumbnails open lightbox preview (filename still opens Files)
- Results ownership: figures prefer per-run frozen snapshots; shared working paths only under the newest declaring run (older runs note superseded paths)
- Results declared: Execution-style expandable run list (only runs with outputs); Execution “Open in Results” expands the same run
- Results: segmented switch between Recorded (by run) and Working directory (scan); rescan only on the scan view

### Interaction (P0)

- Chat ` ```interaction ` fences reference persisted specs at `.prismnext/artifacts/<id>/spec.json`; thumbnail cards with local/bound badges open a RightArea panel shell
- Interaction mode is opened from Chat (hidden from the RightArea mode toolbar); panel shows spec metadata and a placeholder until plot/math renderers land
- Agent tools: `interaction-list`, `interaction-read`, `interaction-write`, `interaction-open` (Literature-style family) + Interaction prompt module — write spec then embed fence in assistant replies

### Interaction (P1)

- `plot.line` / `plot.series` / `plot.scatter` render in the Interaction panel via Observable Plot (lazy-loaded)
- **Local** plots show a deterministic loss-curve sketch; **bound** plots read csv from `resources` (params `x` / `y` columns) with clear error states for missing files or columns

### Interaction (P2)

- `math.surface` / `math.field` render in the Interaction panel via lazy-loaded Three.js (orbit + zoom in-panel only)
- **Local** explicit surfaces `z=f(u,v;θ)` and vector fields with **bindings sliders** updating the scene live; expressions pass a whitelist sandbox (no arbitrary code execution)
- **Bound** math meshes are not supported yet — clear error if `compute: bound`

## 0.6.4 — 2026-07-26

### Chat

- Rename a session from the session hover card; the title sticks (OpenCode auto-titles no longer overwrite user renames), with undo support

- Right Area empty states (no file / no manuscript / browser home / git history / literature BBT banner) use locale strings
