# Angle: Model-construction Methods

> Reference pattern, not a mold — adapt, blend, reorder, or depart as the
> material demands. The bar is a section that reads true, not one that
> matches this file.

Best for economics / management-science theory: players, structure,
assumptions, then the model and its properties.

1. **Players, actions, timing, information, payoffs** — the game/decision
   structure in that order; notation fixed here.
2. **Assumptions** — A1, A2, …: each with a one-line justification (what it
   buys, what it costs). Assumptions the results do not use get cut.
3. **The equilibrium / solution concept** — defined precisely; existence
   and uniqueness stated (proof or reference).
4. **Comparative statics** — the propositions the empirics will test;
   symbolic steps machine-checked (`symbolic-math` when enabled).
5. **Mapping to empirics** — which model quantity corresponds to which
   measured variable (this table saves the Results section).

Check before done: every assumption is used by at least one result; every
proposition states its delivering proof location.
