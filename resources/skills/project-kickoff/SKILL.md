# Project Kickoff

Take a project from empty desk to a grounded, planned study — with artifacts
on disk from minute one, not chat memory.

## When to use

- A new project folder / new study begins
- The user has an idea but no brief, no library, no plan yet

## Workflow

1. **Interview-lite** — at most 2–3 questions: the research question, the
   guessed contribution, the target venue or output form. Do not
   over-interview; proceed on reasonable answers.
2. **Brief** — `research-brief-read` (creates the template if missing) →
   propose the sections → `research-brief-update` after user confirmation
   (one section per call, first person).
3. **Seed literature** — `literature-discover` 3–5 cornerstone papers →
   `literature-stage` them for the chat. `literature-add` only if the user
   asks to keep them in the library.
4. **Roadmap** — `suggest-plan` so the phased plan lives on disk, not in
   chat.
5. **Scaffold** — empirical project → create the first island via
   `experiment-log`; respect Workspace Folder Descriptions for layout.
6. **Git** — suggest an initial commit so the research trail starts clean.

## Rules

- Every artifact on disk beats a chat promise — brief, plan, island first.
- The brief is the intellectual spine; keep it honest and short rather than
  aspirational and long.
