# Pattern: Problem-setup Preliminaries

> Reference pattern, not a mold — adapt, blend, reorder, or depart as the
> material demands. The bar is a section that reads true, not one that
> matches this file.

Best when the formalism serves one central problem — introduce the problem
informally, formalize piece by piece.

1. **The problem in words** — a concrete instance, no notation yet. The
   reader should recognize their own situation.
2. **Formalization, piece by piece** — each definition arrives just before
   the concept that needs it, alternating intuition and formal statement.
3. **The formal problem statement** — the full formal version, one display
   equation or environment, stated only after all its pieces exist.
4. **Immediate consequences** — one or two remarks: what the formulation
   makes easy to see (this is where the Methods section will pick up).

Check before done: no symbol is used before its definition; the formal
statement in item 3 uses only pieces defined above it.
