# Research Reading Notes

Turn deep reading into durable project notes — evidence-tied and reusable in later chats.

## When to use

- The user is reading one or more library papers deeply
- They want reading cards, not just conversational answers
- Notes should link bibkeys and page anchors for later writing

## Workflow

1. Clarify reading purpose (method, gap, related work).
2. Use literature tools with scoped `pages=` / `query=` — avoid whole-PDF dumps.
3. Structure each card: bibkey, problem, method, key findings, limitations, links.
4. Cross-link related papers when the user is building a literature map.
